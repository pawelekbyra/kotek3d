# kotek3d

Płatna społeczność dla osób, które chcą rzucić palenie.

Aplikacja zbudowana w [Next.js](https://nextjs.org/) (App Router, TypeScript).

## Rozwój lokalny

```bash
npm install
npm run dev
```

Aplikacja będzie dostępna pod adresem [http://localhost:3000](http://localhost:3000).

## Build produkcyjny

```bash
npm run build
npm start
```
